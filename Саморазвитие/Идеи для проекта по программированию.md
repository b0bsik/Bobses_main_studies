# Идеи для ПЭТ проекта
## 1. Приложения для отслеживания тренировок
Приложения для андроид для отслеживания тренировок, с возможностью импорта и экспорта таблиц
Также можно сделать графики для отслеживания прогресс в каждом упражнении 
Также расчет по формулам для предполагаемого увеличения вес в упражнениях.
## 2. Приложение или аддон для обсидиана для вывода заметок в виджеты
Приложения или аддон( Решить позже когда обсужу это с нейронкой) для вывода заметок в виде виджетов чтоб они все время были на виду
Нужен функционал с выводом определенной заметки, а также каким либо образом было бы круто реализовать автоматический вывод заметки условно с задачами на день.
Так же можно настроить систему пуш уведомлений с напоминанием о задачах
